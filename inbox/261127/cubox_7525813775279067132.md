# G2算力基建进入减速周期

# G2算力基建进入减速周期

[mp.weixin.qq.com](https://mp.weixin.qq.com/s?__biz=MzI0ODE5NDU5Mw==&mid=2649552809&idx=1&sn=e3c351012e811c2fa5361481163b4814&chksm=f07a371b933d50789e17fb7b1faeae4e8bfbbe1acebd806af0858227ac42513e195646350c32&mpshare=1&scene=1&srcid=1127R6XNTx6yvCkgRX1hZxUp&sharer_shareinfo=e7d417ee94df9db5acaf081a5ca0e897&sharer_shareinfo_first=e7d417ee94df9db5acaf081a5ca0e897)慕峰 太阳照常升起


过去半个多月，作者预测了黄仁勋的离任与复职（《[复盘：如何成功预测黄仁勋回归](https://mp.weixin.qq.com/s?__biz=MzI0ODE5NDU5Mw==&mid=2649552799&idx=1&sn=f0147fa5f75fb8f7893119c7efe9f52f&scene=21#wechat_redirect)》）。关注黄仁勋事件是因为这个事件直接影响全球算力产业方向。

过去不到两年时间，是G2算力基建爆发的加速周期，因AI大模型突飞猛进，G2的AI企业在算力基建方面投入巨大，使得英伟达成为G2博弈的焦点，最终出现黄仁勋离任事件。

黄仁勋事件处置暴露出来美国内部有三派立场：

一是加速主义阵营主导，同时支持美国闭源模型和中国开源模型，主张宽松的出口管制政策。

二是减速主义阵营主导，认为美国算力中心建设导致美国地方能源价格提升，产生噪音等污染，不利于算力基建附近社区的美国民众，主张在利益平衡之前，先限制美国国内的算力基建。

三是安全主义阵营主导，认为中国开源模型的追赶不利于美国维持领先优势，甚至会对美国产生安全风险，主张大幅加强出口管制。在安全主义阵营内部，又暗含着美国主流闭源模型企业（以Anthropic、OpenAI为代表）以安全为借口来打压中国开源模型竞争者的诉求。

很显然，仅从商业视角而言，加速主义对英伟达是最有利的。但随着美国民众社区利益叙事的减速主义阵营与安全主义阵营的合流，美国的政策天平发生了逆转。

曾经是加速主义阵营主导政策，尽管有诸多出口管制强化的讨论，但真正落地时，都留了空间，包括GPU型号、通过云服务提供算力等。一定程度上，英伟达巨额担保的美国国内AI算力建设大循环，也是以海外高利润的灰色收入来提供重要支撑的。

但加速主义没有足够考虑美国民众的利益，尤其是与能源价格问题纠缠在一起，成为更大的通胀议题（包括俄乌战争、美伊战争对通胀的提升），这个议题让共和党在中期选举大败，民主党拿回两院。

让美国国内算力中心建设与美国民众利益相平衡，是这一轮美国减速周期的主要议题。再加上安全主义的诉求，导致美国立法和政策制定的天平彻底逆转。

这就是黄仁勋事件的底层原因。

在这个背景下，过去两三年整个美国算力溢出的窗口期，实际已经接近结束。接下来就是美国政策的全面调整，主要表现在四项与算力阻断相关的法案将打包进入2027财年《美国国防授权法案》并在今年底进行国会审议，即便不通过，明年初民主党新当选议员上任后，肯定也会通过。川普原则上也已经同意，不太可能会对此行使否决权，顶多在部分表述上再争论一下。

川普前两日在接受CNBC采访时仍然支持将落后的美国GPU卖给中国AI企业，如何界定"落后"，会是政策调整争论的焦点之一。如果"落后的"GPU可以出口，那这部分算力云服务也将可以持续。

要深刻理解，美国算力政策的调整是两方面因素导致的，并且一旦以立法形式确定下来，叠加执法趋严，将具有长期性。当前对四项法案还有一些细节的调整，有可能合并成三项法案，但这些都是形式问题，这个实质方向不会改变。

所以，当前美国算力产业的调整，是一次内部利益平衡的过程，包括AI产业与美国民众利益的平衡（加速主义与减速主义的平衡），宽松出口管制与闭源模型企业诉求的平衡（加速主义与安全主义的平衡）。

这是一个方向性判断，美国内部的利益博弈决定方向，方向决定其政策。

事实上，这也是前期过度加速后一次深度的美国金融风险释放，不止是美股公开市场，也包括美国私募债和其他类型的算力基建融资市场。

中国大陆的算力产业也深受影响，同样进入减速周期。

与美国不同，中国大陆的算力基建进入减速周期，主要是因为：随着灰卡的来源受限，国产卡的质量和产能还在爬坡，算力基建的速度也会放缓。

在这个背景下，美国离岸算力对中资企业的云服务也将大幅受限。

一句话总结就是：

美国有卡不让建，中国缺卡放缓建，离岸算力大幅收紧。

美国要解决的是内部博弈问题，中国要解决的是卡源问题。

G2同时进入了算力基建减速周期。这个周期会是一个长周期吗？并非如此。

从AI大模型当前展现出的能力和发展趋势来看，毫无疑问是人类未来最重要的方向，将彻底改写人类社会。从实际需求来看，无论是实物的尖端GPU，还是最优质的大模型，都处于供不应求的状态。

换言之，这个减速周期不是需求侧导致的，而是供给侧导致的。

既然趋势确定，需求预期无限，那G2在算力产业就面临着如何解决供给的问题。

美国侧而言，就是要尽快完成内部平衡，使算力中心建设符合社区民众利益。方案很多，主要是解决电力、水源问题，实际上就是增加建设成本的问题。川普讲要将算力建设留在美国国内，基本逻辑就是，未来美国国内的算力中心建设还将拉动美国国内的能源基建，这对通过AI产业带动美国制造业是有极为有利的。这个成本消耗只要在美国国内，那美国内部受益方就会很多。

这就是美国国内的再平衡之路。

民主党不会拒绝算力中心建设，只是他们为选票考虑，会去跟算力产业谈如何与民众利益平衡。

这需要时间。

中国大陆侧而言，在灰卡受限的前提下，对国产卡的诉求极度旺盛，这将刺激中国大陆半导体产业进入一个新的阶段，这个阶段实际只有真正有尖端技术实力的企业才有资格参与。这个阶段存在技术上和资源上的挑战和困难，需要中国大陆的AI大模型企业与国产硬件企业紧密合作，走出一条完全突破美国硬件模式的新路。

这也需要时间。

对中国大陆的AI模型企业而言，过去两年，受益于美国算力的溢出，搭上了加速主义快车，但这趟车终究不是自己的，是别人掌控的。搭上快车这个阶段非常重要，它让全世界看到，中国大陆凭借自身的人才资源，同样能够实现AI产业对美国最优秀企业的追赶。光有卡是不够的，还得有一群天才的AI人才，更关键的是，让所有人看到这条路是走得通的。这就是过去两三年中国大陆AI企业做到的，把中国大陆开源模型的本地部署和价格优势刻入了全世界的脑海中。

中国大陆的一些AI企业因为过去处于加速主义周期，顺风顺水，感觉能与美国AI企业平起平坐，现在一旦算力受限，就认为这将导致中国大陆的AI模型差距将与美国越来越大，因此寄希望于回到过去那个特殊的、几乎不受控的加速主义周期。

坦率地讲，这是不现实的。

这个美国的减速周期并不以中国大陆的意志为转移，完全是美国内部的减速主义与安全主义合流的结果，美国的政策逆转，不是靠呼吁、施压或者反制就能改变。

换言之，中国大陆AI企业应当放弃幻想，深刻理解美国政策转向的根本原因。与其过度担忧，不如早日转向。

当前，部分AI大模型企业已经下定决心要与国产硬件企业共同寻求突破，这是一条必由之路。

2023年，作者首先梳理了美国半导体产业与其国防系统和市场之间的历史关系，国内半导体产业的各方人士基本都读过这篇文章（《[芯片战争及其应对（下）------美国半导体政策的不同视角](https://mp.weixin.qq.com/s?__biz=MzI0ODE5NDU5Mw==&mid=2649550593&idx=1&sn=82139664dad8af45d67f2120670af9f4&scene=21#wechat_redirect)》）。

在该文中，作者利用美国国防科学委员会（DSB）过去四十多年的报告，详细梳理了美国半导体产业如何诞生于军工，又如何被美国国防体系认为只有市场化的半导体产业才能维持军工优势，进而使美国国防体系长期支持美国半导体产业在全球市场维持优势地位，也即将国防安全议题长期嵌入半导体产业。

当前中国大陆要解决自身的半导体供给问题，要走的其实并非当年的美国道路，而是必须结合中国本土实际，先集中优势力量突破，然后再通过市场去释放。

在资源高度受限、需要自身突破的前提下，再像加速周期时那样一哄而上，已经没有意义也没有可能了。

允许短暂存在泡沫的原因，是以资源的基础供给不受限为前提，通过适当的泡沫来引入各方投资，从而快速建立起相关产业。

在资源高度受限的前提下，靠产业泡沫是无法实现突破的。可借鉴的历史，是日本半导体产业崛起时，通产省的产业政策模式，也即定点资源聚拢，集中突破若干底层技术，然后再进行广泛的市场化。

这种模式下，一定只能是由最顶尖的企业技术人才来主导，集中优势资源。一哄而上并不能解决问题。

要承认当前和未来一段时间是一个算力产业的减速周期，从AI产业的未来看，这其实是一个小周期。这个周期无法越过，美国有美国的问题要解决，中国有中国的问题要解决，各自需要面对的问题是不同的。

要有十足的信心，也要有充分的决心，要相信一切技术问题都只是时间问题，要相信G2大博弈下，其他国家不会轻易单方站队，要相信G2博弈的砝码是多样化的。也就是，当前的"自力更生"并非革命年代的自力更生，而是G2大博弈下的再全球化。

没有什么事业是容易实现的，更不会因为有了若干高智商的头脑，就很容易实现。如果那么容易实现，那它一定不是人类最尖端的事业。

过去一百年，人类最尖端的科技产出，大多数都是大国博弈的直接结果或者衍生物。最伟大的科学家，往往都不是在一个和平舒适的环境中去实现自己的报负，而总是在激烈博弈的背景下，为自己的理想，去实现自己的报负。

最伟大的科技变革，往往源于理想主义者的坚持，而不是现实主义者的适应。AI产业最尖端的科技人才，有着非常强烈的理想主义情怀，要相信，只要理想还在，火炬就不会熄灭。

中国大陆的开源或称开放权重模型是比美国闭源模型更具有理想主义的AI发展路径，对包括欧洲在内的非美世界而言，是更具有安全性和主权性的选择。这不只是市场的选择，也是理想主义的坚持，这种精神层面的感召力叠加现实的考虑，未来将是打破美国闭源模型霸权的关键，也是决定包括欧洲在内的其他国家不会轻易完全站队美国的关键。

作者认为，在过度加速之后，进入一个减速周期，对G2而言，对全球而言，都不是坏事。要利用好这段时间，重新审视AI产业对人类的影响，重新思考除了AI、半导体、算力产业之外，还有哪些重要的事没来得及足够关心。

中国大陆与美国在经济上面临的主要矛盾是不同的。美国的制造业早就空心化了，All in AI其实是在通过AI产业来带动制造业的部分恢复。中国大陆当前处于制造业尽皆优势的时代，未来相当长时间内，还将保持这个优势。如何充分发挥好这种优势，如何解决好内需问题，才是关键所在。

对产业而言，在过度加速之后，适度冷却，认清形势，找准自己未来的方位，才是当前最重要的事。

以上。
