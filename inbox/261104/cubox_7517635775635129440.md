# 一个小人物在数据江湖

国庆前「elsewhere」发了一篇[关于数据的文章](https://mp.weixin.qq.com/s?__biz=MzYzNTA3NTgwNQ==&mid=2247484549&idx=1&sn=f6428353eaa8455d191f7110bcc3c07e&scene=21#wechat_redirect)。文中着重写的那几家明星数商只是掐尖的公司，但更庞大的是这个行业的水下。过去一段时间，我了解到的数据行业的辐射面之广、行业现状之惊诧，还是超过了我的预期。

如果AI在你想象中是个往来无白丁的地方，那数据行业会推翻你的这个想象。这里更像是清晨的北京三元里市场，有售价成千上万的珍稀食材，也有几块钱一斤的芹菜。来这买菜的人来自市中心、使馆区、高级小区，也有无法动迁的老小区。三教九流，在共同的喧嚣里买菜卖菜。

就在动笔前，我认识了小武。他简直是这个行业中众生相的集大成者。

一年前，小武还是个 AI 应用的边缘创业者。创业三年，他没有拿到什么大结果：用户不付费，VC不投资，几百万积蓄净赔一空。为了糊口，小武开始当外包，接一些给公司做模型部署的活。其间，因为跟倒腾token的三教九流打交道，他意外地成了一名数据倒爷。

过去一年，小武在海外地下小网站爬过数据，去过流水线般的千人标注工厂，在硅谷过追踪过Surge的专家网络。他见过的中转站站长有卖数据年入千万的，也见过踩到红线消失不见的。而他很幸运，干这个没多久，赔掉的积蓄就尽数赚回来了。

或许因为他时而眉飞色舞、时而幻灭失落的讲述，这个行业里沉默而数量庞大的群体，在我眼前清晰生动起来。

数据这个行业，改写了小武的创业观，但也令他流连忘返。他甚至有个偏激的说法是，做AI只有三条路：卖公司（融资）、卖token（模型厂/中转站）、卖数据。对他这种没法融资也没法进模厂的人来说，卖数据最香。

数据行业看似遥远，实则和每个人都有关。它们把每个人的头脑抽取给模型，又终将影响每个人的生活。头部数商，更接近于研究，生产题目、环境和轨迹。但其下还有各式各样的人在奔走、流转、交易。

而小武的故事，会让你更真切地理解这一切是如何发生的。

文中的"小武"是化名。因为本文主人公的故事，莫名让我想起了电影《小武》。以下除了主要基于其本人的故事之外，也集合了多个我访谈到的真实故事。为了防止被对号入座，部分细节和故事线有模糊化处理。

## 万物皆有数据

第一次意识到数据生意的存在是今年春天。

一个给模厂找数据的师兄问小武能不能从海外网站爬一批指定视频，他干了好几年泛娱乐，确实知道去哪爬，但这也算数据吗？

还在创业的他找了个技术好的员工，没几天就爬了几十个T。几乎没有成本，电费+网费+员工工资，折合每T几十元。但师兄居然真的以4万元/T的价格收下了。第一笔数据生意，就让他入账一百多万。这比应用创业轻松多了。

当然也不是每一笔都这么赚。小武后来也试着卖给其他有视频产品的公司。但这次，价格一路从4万砍到600，最终只以1000元/T成交。

这件事让小武明白关系是一切的前提：及时知道谁要什么数据、谁能出得起钱、该卖给哪一个人，以及和这个人建立足够的信任。

他发现，这个行业倒爷的层级很多，层层转包，层层抽水。能链接到的关系越靠上，价格就越高。最靠近模厂的那一层供应商是不变的------就是那几家明星数商，他们除了自己生产，也承担了模厂的集成商角色，每个小供应商都想认识他们。

小武跟他们既不是校友也没共事过，于是决定修炼自己。他收到过师兄许多五花八门的需求，比如菜单菜谱、药品说明书、手写病历、游戏源码、主机游戏录屏、影视公司废片......师兄告诉他，模型要替代所有劳动力，就要学会所有行业的知识。真实、优质的数据和轨迹现在供不应求，模厂肯定会买，只要他愿意到世界的各个角落去找。

于是在一个月后，小武彻底关掉了应用项目。他决定阶段性做一个数商游民。

他跑到硅谷那些在Surge上打零工的人身边。像Surge这样的标注众包平台，很多国内模厂想要他们的数据。他打入留学生群，把人脉广、又在Surge上接单的人发展成下线，等他们把Surge的专家网络摸透了，他逐个找到，让这些人把在Surge上做的题原样下载一份给他，他付跟Surge相同的酬劳。能多赚一份又毫无成本，几乎没人拒绝他。

他跑到国内的影视标注工厂里。那是个千人工厂，工人是电影和导演等专业的学生和从业者，每天给AI标注分镜机位、相机角度差、画面配比等，把自己学到的影视知识教给AI。他们的报酬是每天300元不到，约等于用Seedance 2.0生成20条标准15秒视频的费用。

他跑进专门的游戏实机视频公司。世界模型需要能体现物理规律和复杂交互的数据，3D 游戏的玩家操作数据、建模参数是很好的替代品，有血量、重力和撞击力度的完整记录。一些非头部的开放世界游戏公司已经在卖这类数据，至于不愿意卖的头部游戏IP，这些公司会专门招募员工，边玩边录游戏实况。他能找到上亿小时的主机游戏视频。

他跑进大学实验室里。科学家的实验过程数据，是AI4S的珍贵食物。一篇论文做的千百次实验，对模型有价值的不只是跑通的实验，还有失败的、修改的轨迹，模厂给他的任务是买下学者们的所有实验记录。跟学者们打交道，钱不是万金油，他们更关注的是学术reputation：我卖数据的消息会传出去吗？实验里有我学术不严谨的证据吗？如果AI用我的材料证明了某个猜想，成就是算我的还是模型的？

跑动中，小武看见一个微缩的社会。**任何人、任何行业、发生的任何事，都可能成为数据，而模型几乎在每个行业都找到了买办，有一定渠道的普通人** **主要** **抓机会** **，都能** **快速变现。**

圈子也在迅速收窄。容易获得的简单数据在跌价，但高质量专家的数据反而在涨。数据的大盘没有变小，但普通人想参与更难了。

## 公司入殓师

夏天，小武在硅谷认识的一位朋友给他发了一份商机，说手头有硅谷公司的数据，让他帮忙在国内找买家。这是一个更高效的收数据方法：给破产公司、半死不活的公司"收尸"。

这份商机单上，有上百家愿意出售数据的公司待价而沽。什么行业的公司都有，从消费品------香水、补剂、服装、游戏；到医疗------专科、理赔、宠物医疗，到线下服务------餐厅、工业设计、房产开发、物业，到科技------SaaS、软件开发，职能性公司------电商、物流、销售，甚至一级市场------孵化器、VC的投后管理......**看起来，任何行业、任何公司的数据都可能被买卖。**

当他打开其中一家的描述详情时，震惊了。**这份数据清单，几乎完整记录了过去十多年，这家SaaS公司从获客、签约、交付、研发、售后服务、内部管理到日常协作的各个环节** 。

小武感到毛骨悚然。如果模型能够学会所有这些，人类在职场上还有什么"专家"、"经验"可言？但对他自己来说，买卖这类数据显然比单个真人数据的价值要赚得多。所以他一边恐慌，一边卖力搓合。最终他为这家公司找到了一家国内模厂买单，以300万美金的价格成交。

做完这一单后，朋友那边又转来一些模厂的诉求：求购AI应用公司的pivot项目，预算从几万到一百万美金不等；还有中国模厂找到小武，问他有没有银行的不良资产名单，来找到那些表面正常经营，实际濒临破产的公司。

有次小武跟一位投资人闲聊提起这些，对方也受了启发：基金这么多半死不活的被投，如果能把它们的数据打包变卖，不就相当于回购了吗？

**所有公司的数据里，又以AI应用公司的数据最有价值。** 有些公司的harness做得好，任务轨迹够长，用户跟AI合作、反馈、修改的记录都留存在数据里，是模型天然的学习素材。

有段时间，小武经常替模厂去问应用公司卖不卖用户轨迹。作为一个前应用创业者，他当然知道这种问询有多无礼，相当于给产品宣告死亡。刚开始，小武吃的闭门羹都很干脆。但他能感觉到出创业者们在盘算那个trade off：我不卖，我的竞品会不会卖？我不卖，模型就学不会我的场景了吗？

人类在纠结，模型在一刻不停地学习。过了一段时间，有创业者会主动找小武卖数据，但模厂已经提高标准了：要高价值行业的，要用户量大的，要用户能在产品内完成最后一步的。愿意付的价格也从花钱买，降格到了给API打折。等到整个AI应用赛道也跌落到冰点，一些创业者甚至愿意把数据免费送给模厂，只为了把关系搞好。小武猜测，这是在为被收购、或创业者自己的下份工作找退路。

小武会想起从前融资时，他总要被拷问如何跟模厂竞争。这几年来，一些应用创业者对模厂或躲避、或迎战、或暗自希望被收购。但万万没想到还有这一层存在的意义。

## 闭环

但AI应用公司终究还是数量有限的，达到PMF的更有限。所以怎么才能让模型拿到更多人类使用AI的痕迹？

小武曾经以为，只能靠一些运营专家网络的数商扩大产量，但后来他发现了一个更高效的方法：中转站。

小武告诉我，许多国内大厂都有调用 OpenAI 和 Anthropic API 的需求，又不能走公开渠道，只能通过一些专门To B的中转站去海外买token。

这是利润极高的生意。海外的羊毛党通过批量注册start-up申请 AWS 和 Google Cloud 扶持额度的方式，每个月申请到数百个start-up的扶持名额，每家每月净薅 小几万美元额度。而国内的中转站从这些人手里以低折价格拿到API，再找一个中间的价格卖给大厂。

对国内中转站来说，油水最高的地方还不在这里，而是卖数据。等企业客户调用起来了、任务轨迹沉淀下来了，他们会把这些数据抽走，转卖给其他公司。高人才密度的组织，调用SOTA模型的轨迹数据，这本身就是非常有价值的蒸馏材料。

这桩生意的性感在于没有额外成本，只有复利。中转站只需要定时把数据打个压缩包，发过去，过段时间账面上就会出现一笔记作其他名目的收入。

**有些** **中转站甚至把这两种业务组成了完美闭环：用卖数据的收入做token补贴客户，客户用得更多，带来更多数据，再继续出售。** 据小武估算，即使是二线互联网公司，一个月花在中转站上的钱都有2000万美金。许多中转站今年的利润达到了千万人民币。

这一切在夏天开始降温。据说是有一家大厂在买数据时，赫然买到了自己使用中转站的轨迹数据。自己买的To B服务，不仅扒自己的数据出去卖，还卖回了自己头上，大厂管理层勃然大怒。这在数据行业引起了严重的连锁反应。此后，一边做中转站一边卖数据的人不少都销声匿迹了。

虽然自己不做中转站，这件事还是让小武从赚钱的狂热里清醒了一点。一个他心知肚明的事实是：卖数据的普通人、他和所有倒爷们、一些头部数商们、甚至模厂自己，很多做法都处在灰色地带。

黑天鹅事件的出现往往是行业的转折点。上个月成立的国家数据集团无疑会加快这个节奏。

## 瘟疫

但为什么这种灰色交易会席卷得这么广泛？

作为一个在芸芸众生中辗转的倒爷，小武能感受到那股狂热与绝望交织的潜流。在他看来，敢用最狂野的路径收集数据的不是想赚钱的倒爷，而是一些模厂。

"有任何方法提高模型能力，都会不惜一切代价去做。即使被曝光，都无所谓。"对模厂来说，明牌是：智能就是劳动力，就是商业化。只要这笔账算得过来，这台机器就会继续吃下去。

落到每个个体上，又都有共同的无力：大家都心知肚明，AI是通过淘汰人来进化的。买卖数据是把自己脑子里的东西上贡给模型，直到有一天他们不再被需要。今天连在模厂、训模型的人都在被裁员。

但好像又没有人愿意停下，每个人都想抢泰坦尼克号的救生船。

小武至今对自己做应用时融不到资耿耿于怀。在而立之年把自己的全部积蓄投入创业，不可谓没有创业精神，但小武依然对这个时代无所适从。对他这种进不了模厂、也无法在应用上卷出一条生路的人来说，数据突然像是最后的战场，于是他复仇般投身于此。

"我卖数据给那群在融资上拿到大结果的人，相当于我也从投资人手里赚钱了。"

那之后呢？

小武觉得，如果模型完全取代人类还要十年，那他的数据生意也还能做十年。我跟他说，很多创投行业在做数据的人都说这是个短期生意，很快就会结束。他说，那是因为他们还想做能融资、资本化、天花板高的事，他只想把这件事当成一桩生意。

至于十年之后，"AI和人类必有一战，要么AI被驾驭，要么赛博朋克。"但那是太遥远的事，也跟他一个小小数商没有关系。

一位数商朋友跟小武讲过一件事：有次他们请了一批专家来标数据，时薪上千元。其中一人标着标着就崩溃了，开始痛骂：你们天天把我们脑子里的东西注入到机器里，AI到底是在拯救人类还是毁灭人类。

他这位朋友那几天想了很久，最终承认事实的确就是如此------搞 AI 的一些人大赚特赚，但很多人的生活似乎都没有变得更好。一些人之所以可以赚很多钱，是因为他们更聪明、更努力、更会叙事，还是仅仅因为专业选得好？

对话就停在这里，他们谁也没有再说下去。
