**"企业落地 Agent 最大的问题，不是模型不够强，而是断点太多。"**   

10 月 29 日，腾讯全球数字生态大会上，腾讯集团高级执行副总裁、云与智慧产业事业群 CEO 汤道生开场便指出这个问题。  

今天，Agent 正在成为新的生产力形态。员工用 AI 提效已经步入轨道，但企业 AI 落地却存在明显的 Gap。  

层出不穷的 AI 新功能到底怎么用？员工已经在用 Agent 做产出，每个人走得更快了，但彼此之间的协作并没有提效，怎样成为一个 AI 赋能的组织？能不能从"超级个体"发展到"超级组织"？  

**这些都是过去一年中，市场问得最多的几个问题。**   

还有腾讯员工注意到这个微妙变化：最早大家会在个性签名里放一个和自己有关的文档，让同事们优先读它、方便工作推进；但今年放的不再是文档了，而是一个机器人------有什么事、先问这个机器人。AI 正在从个人提效的工具，走向工作协作的入口。  

**入口变了，但背后的资产、权限、上下文，仍然处在分散的孤岛上。**   

企业如何用 AI 做更准的决策、更快的执行？如何把人、工具、系统和数据连起来，让大模型理解业务上下文，真正进入工作流程？这是本次腾讯数字生态大会在回答的问题。

**建立 Agent 生产力系统**   

本次腾讯数字生态大会，腾讯给出的解决方案是：围绕"办公协同、数据管理与业务执行"三大场景，持续开放 WorkBuddy Agent 平台能力，打造"全场景、高效能、更放心"的 Agent 生产力系统，帮助企业建设可运营、可进化的智能生产力。  

**会上，以 WorkBuddy 为工作台的一体化套件 Buddy One 正式发布。**   

WorkBuddy 企业版以统一账号、统一积分、统一存储把腾讯办公产品连成套件，腾讯文档、腾讯网盘、ima 知识库、Ardot、CodeBuddy 等工具各补一环，Agent 由此从个人助手变成团队里的"新同事"。  

**这套套件化的能力，已经落到相当规模的客户里。**   

自今年 3 月上线以来，WorkBuddy 企业版已落地 50 多个行业，覆盖中国企业 500 强中的 50%、企业 100 强中的 60%，开放平台伙伴和开发者超过 5 万家，上架 Skills 超 20 万。  

需要注意的是，在这届大会的 AI 产品发布台上，为期两天时间、四大版块、七场议题、44 场发布，把这套系统拆解到办公、业务、数据、安全和工程的每个环节。**其中，"办公协同"和"业务执行"，是 Agent 应用在"全场景"落地的重要载体。**   

从 WorkBuddy 到腾讯文档、腾讯网盘、ima 知识库、腾讯云 Mall......共计 14 款 Agent 产品专题发布，这场发布由**十字路口 Koji** 主持。

**Agent 新同事：从超级个体到超级组织**   

AI 生态高速发展，但大量 AI 能力还没有完全融入到企业的办公日常。  

为解决这一问题，WorkBuddy 企业版联合腾讯文档、乐享等腾讯办公产品推出新版本------智能体套件化升级，把腾讯生态内的各个产品融入 WorkBuddy 的办公台。这也是本场大会的重量级产品更新。  

**这次升级的核心，是打通员工办公中不同账号、不同权益之间的壁垒，让组织级 AI 能够理解全量上下文，从而真正支撑组织提效。**   

WorkBuddy 高级产品经理李俞指出："我们把所有腾讯的办公产品放在一个订阅里，通过 WorkBuddy 的底座把所有产品打通，把管理后端收进一个控制台，解决管理分散的问题。"  

通过这次升级，企业订购 WorkBuddy 企业版后，每一个席位都会带上 5 款腾讯办公智能体，不用分别单独购买。  

以前，每个产品有自己的 AI 功能，用户需要额外购买高级权益和积分；这次腾讯把所有产品用量接入同一个企业共享 Credit 池，所有员工在所有产品上使用 AI 功能，都通过这一套 Credit 扣除，企业也只收到一套账单。购买 WorkBuddy 企业版之后，用户可以在一个办公工作台里处理所有管理逻辑。  

这套办公流程融入企业日常工作后，将形成一个效率飞轮：**个人验证有效的经验被沉淀为 Skill 和上下文，复用到团队，再沉淀为组织智能资产，帮助企业完成个体经验的复制，最终走向超级组织。**   

其中，面对 Agent 时代对文档编辑的新要求，腾讯文档重新设计了编辑器。  

腾讯文档技术负责人伍时琅介绍，**腾讯文档面向 Agent 重新设计了编辑引擎，支持多人与多个 Agent 在同一份文档中协作，选中内容即可由 AI 原地修改，版本可回溯。** 引擎兼容 Office 三件套，也支持 Markdown、HTML 等 AI 原生格式，并打通网盘、资料库与知识库，让 Agent 能读取企业资料、回写交付成果。  

目前，这套能力已在 WorkBuddy 中落地，企业也可通过私有化中台、在线中台或本地编辑 SDK 三种方式接入。

**ima 就像是用户和 Agent 的"第二大脑"。** 发布会上，ima 高级产品经理翁祺展示了 ima 的笔记、录音、网页剪藏等知识沉淀功能；同时，ima 通过原生嵌入、MCP、Skill 向 WorkBuddy、元宝及外部智能体开放，正在把知识底座包装成可外接的能力对外开放。目前，ima 在 WorkBuddy 和元宝中的累计调用次数超 2 亿次。  

为了丰富管理、理解和应用分析能力，ima 今年还推出了知识 Agent Copilot，内置记忆系统，可以记住用户背景、习惯与推进事项，还能感知用户当前浏览内容；ima 知识号上线了更丰富的运营工具和付费订阅等功能。翁祺称："我们希望让知识不再被锁在某一个工具里，而是成为整个生态可以共用的底层能力。"  

**目前，ima 已汇聚 1300 万月活知识工作者，帮助用户沉淀与管理超 12 亿知识内容；知识号覆盖金融、法律、教育、职场、科技、政务等 20 多个行业，实现超 5.2 亿次知识共享。**   

在 ima 上，有一位深圳 B 站百万 up 主**"** **历史老师定哥"** ，把自己过往教学 26 年的资料放进 ima 知识库、做成 Skill；他还在教室里放了一台设备，以前老师没太多时间回答的问题，现在学生可以通过 ima 提问、从库里直接得到答案。  

在人机协同编辑的腾讯文档、ima 知识库之外，关于 Agent 如何提高组织内的工作推进，本场还有非常多的产品发布和升级。  

比如，**腾讯网盘** 给这些产品带来了一个存储的基座，让同一份工作资产既能被人找到，也能被 Agent 按授权取用；围绕"为 Agent 供给可信的上下文"，**腾讯乐享** 在可信连接和可信治理上继续升级，增加了可信索引，便于用户构建知识图谱、对齐实体和检测。  

作为面向产设研的 AI 设计协作平台，**腾讯 Ardot** 带来了一个 AI 设计分身，它可以记住项目的设计规范、组件、业务边界和设计师反馈，并且按项目分开管理，非设计岗位也能用它批量产出物料；**CodeBuddy NPC** 现在也已经不只是生成代码，而是开始成为团队流程中的实际贡献者，甚至核心贡献者。在一些团队经过评审、最终被团队接受并合并进代码库的 PR 中，有 40% 到 50% 的 PR 有 NPC 贡献。  

从文档、知识库到设计、研发，WorkBuddy 企业版套件化把身份、计费、权限和上下文收束成了一个组织级 Agent 入口。

**对企业而言，它的价值在于降低多工具采购、重复授权和分散治理的成本；企业采购 Agent，获得的将是一套能沉淀上下文、可治理、更方便组织迭代的 AI 底座。**   

**Agent 新生态：业务里的 Agent，怎么长出来？**   

办公协同层解决的是"人怎么和 Agent 一起工作"，业务执行层要回答的是另一个问题：**Agent 怎么进入企业的真实业务流？**   

这里的断点不是文档和代码，而在业务系统、信息供给、实时交互和经营决策中。  

**腾讯云通过 Agent 生态，逐个打通其中的断点。** ADP 帮助企业自建 Agent 底座，元宝搜索供"信得过"的信息，天籁和实时智能处理音视频交互，WAND 做多模态生产，MAGIC AI 和云 Mall 进入营销和经营场景。

**腾讯云智能体开发平台 ADP 是企业自建 Agent 的底座，它帮助企业完成智能体从搭建到治理的全过程。**   

为了让企业看到更少的 Token 消耗、更高效的信息处理，以及更多有效的信息，ADP 把接入与安全、构建与集成、部署与运行、观测与优化，以及使用与协作贯通起来，为智能体和业务应用提供全生命周期支持。  

在网络接入方面，无论资源位于腾讯云 VPC、本地机房还是其他云环境，ADP 都可通过专线、PrivateLink、云联网等方式完成接入；接入后，相关网络连接能力可被复用。对于私有化部署与信创环境，ADP 已适配多款数据基础组件，包括数据库、对象存储和向量数据库。  

**本次升级，ADP 还将智能体和站点服务两个构建对象结合起来，配置、预览、调试和评测也能在同一工作区衔接完成，边聊边改，贯穿整个全生命周期。**   

腾讯云 ADP 产品负责人马雁翔介绍，"在智能体的观测优化上，我们带来了新增的业务反馈驱动调优，让业务人员用自然语言指出问题和期望。在使用与协作环节，通过企业统一的智能体入口 AgentPortal，平台管理员可以按部门和职能授权分发智能体，**同一个智能体也可以授权给多个部门共享"。**   

这些能力也能进入 WorkBuddy。企业在 ADP 上构建的智能体和 Skill，可以统一分发过去；员工也可以通过在 WorkBuddy 安装并授权 ADP 连接器，在 WorkBuddy 中验证有效的工作流，可以通过连接器转成 ADP 企业智能体，再由企业统一管理、分发。  

**如果 ADP 解决的是"Agent 怎么建、怎么管"，元宝搜索解决的就是"Agent 凭什么信得过"。**   

为打造"可靠可信"的搜索基座，元宝搜索全面升级。元宝搜索通过多源召回、排序精选、结果增强、结构化返回，一次调用全部完成，它回传的是结构化证据和可引用来源，信源来自全网公开资源、腾讯生态与垂直领域，且实时更新。  

对 AI 业务负责人来说，你不必自建搜索团队，一次接入即可上线，按调用量计费；对模型型团队来说，开放域实时知识变成可引用依据，结构化字段直连上下文，结论可溯源。对最终用户来说，元宝搜索答案更新、更准、有出处，每个结论都能回溯到原始来源。  

**目前，元宝搜索已经在元宝、混元、WorkBuddy、ima、腾讯新闻、QQ 浏览器、搜狗输入法、腾讯视频、FIT 腾讯金融科技等等腾讯全线核心产品里完成规模化验证，索引规模达千亿级，日均调用量达数亿次。**   

元宝 AI 搜索总经理叶莎妮表示，"我们还在做下一步，即将推出元宝联网问答 Agent，把这套能力直接封装成一个开箱即用的问答产品。"  

信息供给之外，Agent 进入业务还需要"听得懂、说得好"。腾讯天籁实验室是腾讯内部聚焦智能语音方向超过 8 年的一个团队，它支持腾讯会议、腾讯元宝、搜狗输入法、腾讯地图、QQ 音乐、企业微信等业务。**这一次，腾讯天籁发布了"语音理解"、"语音生成"和"同声传译"三款大模型。**

腾讯云副总裁、腾讯天籁负责人商世东介绍，天籁语音理解大模型聚焦多模态、多讲话人、多语种和多轮精修：借助多模态能力，屏幕分享、上传的文档、参会人列表和过往会议摘要等都可以辅助转写；交替或重叠发言时也能区分讲话人；支持 16 种语言及多种方言。  

**天籁语音生成大模型采用端到端全链路架构，在训练末段从人类听感的角度引入奖励函数，不仅能聊天、会共情、会说方言，仅需 5 到 10 秒音频即可复刻声音。** 天籁同声传译大模型可以在讲话人持续发声的同时完成翻译输出，并保留讲话人的音色。  

腾讯云音视频 AI 品牌 WAND 发布了 WAND-Vega 多模态应用模型：Vega-Image、Vega-Video 和 Vega-VL，电商套图、爆款复刻、白模预演等玩法，客户拿来就能直接用；升级之后的腾讯云音视频实时智能产品，语音识别延迟在 300 毫秒内，停顿、附和、长串算式和口语表达都可识别，**实时视觉可以实现一张图分钟级生成数字形象，支持直播中的实时换装。**   

**交互能力之上，Agent 还要进入企业的营销和经营决策。**   

为了让 AI 真正进入业务，腾讯企点营销云 MAGIC AI 升级 2.1 版，推出 WorkBuddy 上的 Buddy 应用，在 WorkBuddy 里就能按权限直接拿到 MAGIC AI 上的活动效果和会员数据，然后按公司的模板生成经营分析报告，发送给管理层，用来决定下一轮的商品、预算和打法，给出的建议更贴合企业的背景。  

**在一个商城启动阶段，怎样低成本用 AI 赋能？腾讯云 Mall 发布了一个长在商城里的 AI 运营搭档------云小莫。** 它背后是 9 位经营专家，如果是初次做私域的品牌，你只需要告知开业主题和主推品，云小莫即可生成活动初稿，同步输出开业券、会员和分销激励方案，确认即可一键配置。  

整体来看，办公协同层是"把工具收进一个工作台"，业务执行层是"把能力拆开、按场景供给"。**企业不需要一个万能 Agent，它需要的是在每个业务断点上都有一个能接住的 Agent。**   

**不止应用，还有数据、工程、安全**   

**腾讯 AI 产品发布台两天 44 场发布中，本场 Agent 应用是其中离企业最近的一层------办公协同和业务执行层。**   

其余产品发布分布在"数据"、"安全"、"工程"三个版块，构成这张产品地图的另外三边。**这三层虽然不直接面向企业用户，但它们决定了应用层能不能真正跑起来。**   

其中，Agent 数据版块用六款产品串起"懂---存---跑---自治"的完整链路。Agent 要用好数据，得先读懂业务口径，再存得下多模数据、扛得住高并发访问，最后让数据库自主运维。  

Agent 工程版块分三场议题，覆盖 Agent 托管、运行底座、存储与上下文、可观测与网关，直到模型服务、推理加速、私有化部署与数据灾备。Agent 开发出来之后，要有地方常驻、有平台统一管理、有底座支撑规模化运行，模型能力还要按需取用、成本算得清楚。**这是 Agent 高效能的关键。**   

Agent 安全版块的七场分享从调用链路、云上基座、主动渗透，延伸到业务风控、游戏安全和身份核验。**正如主论坛上汤道生所提到的，腾讯以"行为可控、过程可溯、数据可管"构建可信 AI 治理体系，把单点防护编成一张网。**   

它们共同构成了一张企业 Agent 生产力系统的产品地图：**应用在前台接任务，数据让它懂业务，安全为它划边界，工程保证它跑得稳、用得起。** 最终让企业 AI 从"用上"到"用好"，让 AI 真正进入生产流程、创造生产力。
